# Speedy MCP Guides

One guide per MCP server. Each explains **what to add to your project's
`AGENT.md` / `CLAUDE.md`** so an AI coding agent uses that server as effectively
as possible — including a ready-to-paste instruction block.

| Server key | Binary | Guide | Purpose |
|------------|--------|-------|---------|
| `speedy` | `speedy-ai-context-mcp` | [speedy.md](speedy.md) | Semantic + keyword code search |
| `speedy-lc` | `speedy-language-context-mcp` | [speedy-lc.md](speedy-lc.md) | Code graph: skeletons & impact analysis |
| `speedy-text` | `speedy-text-context-mcp` | [speedy-text.md](speedy-text.md) | Text-symbol search & project-wide rename |

To register these servers in your AI tool, see `../SETTINGS_MCP.md`.
For installation and first-run setup, see `../FOR-IA.md`.
